คาสิโน (Casino)
วัตถุประสงค์
โปรแกรมจำลองคาสิโน(Casino)ผ่านหน้าจอคอมพิวเตอร์ (Terminal): 
จัดการผู้เล่นโดยใช้เงินสมมติ เล่นเกมทอยลูกเต๋า และติดตามผลลัพธ์

วิธีใช้งาน (Terminal)
python3 Casino.py หรือ ./Casino.py 
เพื่อเข้าสู่เกม CASINO 🎰
โดยที่จะมีเมนูและที่เลือก (1-7)
1. สร้างผู้เล่นใหม่
2. เล่น Dice
3. ดูประวัติ
4. ดู Leaderboard
5. เติมเงิน
6. ลบผู้เล่น
7. ออก

เลือก (1-7): ...

คุณสมบัติ
1. ผู้เล่นสามารถตั้งชื่อเองได้ เมื่อสร้างผู้เล่นเสร็จแล้ว ทุกคนเริ่มต้นด้วยเงิน 100 บาท
2. เกมทอยลูกเต๋า (Dice): วางเดิมพัน จากนั้นทายผลว่าจะเป็นแต้มต่ำ (LOW: ผลรวม 1-7) หรือแต้มสูง (HIGH: ผลรวม 8-12) โดยดูจากแต้มของ🎲ลูกเต๋าลูกแรกที่ปรากฏ 🎲ลูกเต๋าที่สองกับรวมปรากฏเป็น ? 
เมื่อผู้เล่นเลือกแต้มต่ำ (LOW: ผลรวม 1-7) หรือแต้มสูง (HIGH: ผลรวม 8-12)เลย
จะมีเฉลย ทั้งสอง🎲ลูกเต๋า และ ผลรวม
3. สามารถดูประวัติการเล่นของผู้เล่นแต่ละคน ว่าเกมอะไร เดิมพันเท่าไร และผลเป็น ชนะ แพ้ หรือเสมอ
4. ตารางจัดอันดับ (Leaderboard) เรียงตามยอดเงินคงเหลือ ชนะและแพ้ พร้อมแสดงอัตราการชนะ 
5. เติมเงิน ผู้เล่นสามารถเติมเงินได้
6. ลบผู้เล่นพร้อมประวัติการเล่นได้
7. ออกเกม CASINO 🎰ได้
8. การตรวจสอบข้อมูลนำเข้า (Input Validation): 
ชื่อว่างเปล่า
ชื่อซ้ำ
ผู้เล่นไม่มีอยู่ในระบบ
รองรับกรณีเลือกเมนูไม่ถูกต้อง
ป้อนข้อมูลที่ไม่ใช่ตัวเลข
วางเดิมพัน <= 0 / เงินไม่เพียงพอ /หรือการทายผลที่ไม่ถูกต้อง
9. ผู้เล่นที่เงินไม่พอหรือเงินหมดจะวางเดิมพันไม่ได้ ต้องเติมเงินก่อนจึงจะเล่นต่อได้
10. ชนะได้เงินเท่ากับเงินเดิมพัน แพ้เสียเงินเท่ากับเงินเดิมพัน (จ่าย 1:1)
11. Leaderboard ไม่ error เมื่อผู้เล่นยังไม่เคยเล่น (แสดง 0%) และถ้ายอดเงินเท่ากัน คนที่สร้างก่อนอยู่อันดับสูงกว่า
